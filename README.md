# 🧠 Autonomous Agent in a 2D Grid World (Q-Learning)

This project simulates a simple autonomous agent that learns to navigate a 2D environment using **Q-learning**, a classic reinforcement learning algorithm. The agent learns to reach a goal while avoiding randomly placed obstacles — all visualized using `pygame`.

---

## 📦 Project Features

- ✅ 2D grid world with obstacles, start, and goal
- 🧠 Q-learning for agent decision-making
- 👀 Visual replay of the trained agent
- 📈 Dynamic training with live feedback
- 💥 Obstacle avoidance + goal-seeking behavior

---

### ✅ Requirements
- Python 3.8+
- Pygame
- Numpy
